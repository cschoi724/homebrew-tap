# Cschoi724 Tap

## How do I install these formulae?

`brew install cschoi724/tap/<formula>`

Or `brew tap cschoi724/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cschoi724/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
